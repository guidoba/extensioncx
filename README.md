# 🧩 Instalación de la extensión

Podés instalar la extensión directamente desde el código, sin necesidad de publicarla en una tienda.

## 🟦 Google Chrome

1. Descargá o cloná este repositorio.
2. Si descargaste un `.zip`, descomprimilo.
3. Abrí Chrome y entrá a:
   `chrome://extensions/`
4. Activá **Modo desarrollador**.
5. Hacé clic en **Cargar descomprimida**.
6. Seleccioná la carpeta donde se encuentra el archivo `manifest.json`.
7. ¡Listo! La extensión ya está instalada.

## 🟦 Microsoft Edge

1. Descargá o cloná este repositorio.
2. Si descargaste un `.zip`, descomprimilo.
3. Abrí Edge y entrá a:
   `edge://extensions/`
4. Activá **Modo desarrollador**.
5. Hacé clic en **Cargar descomprimida**.
6. Seleccioná la carpeta donde se encuentra el archivo `manifest.json`.
7. ¡Listo! Ya podés usar la extensión.

## 🦊 Mozilla Firefox

1. Descargá o cloná este repositorio.
2. Si descargaste un `.zip`, descomprimilo.
3. Abrí Firefox y entrá a:
   `about:debugging#/runtime/this-firefox`
4. Hacé clic en **Este Firefox**.
5. Seleccioná **Cargar complemento temporal...**
6. Buscá y seleccioná el archivo `manifest.json`.
7. ¡Listo! La extensión ya está cargada.

> **Nota:** En Chrome y Edge tenés que seleccionar la **carpeta** que contiene el `manifest.json`. En Firefox tenés que seleccionar directamente el archivo `manifest.json`.

### 🔐 Seguridad

El código fuente de la extensión está disponible en este repositorio para que puedas revisarlo antes de instalarla.
